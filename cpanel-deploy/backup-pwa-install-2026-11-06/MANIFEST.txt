What changed
------------
pwa.js
- beforeinstallprompt is no longer preventDefaulted when the custom install
  banner cannot appear (already installed, or the user closed it earlier).
  Previously the event was captured and never prompted, which is exactly the
  Chrome warning "preventDefault() was called, but prompt() was never called".
- Install buttons ([data-pwa-install-trigger]) start hidden and are revealed
  only when the browser offered an install path (or on iOS, where the manual
  sheet is the path). No dead Install button.
- The stored event is consumed once, guarded with try/catch, and dropped on
  pagehide. prompt() is only ever called from the user's click.
- The install card is hidden again if no install path exists.

config/pwa.php and sw.js
- PWA_VERSION and SW_VERSION move 1.3.1 -> 1.3.2 together. The service worker
  keys its shell cache without the ?v= query string, so a JS change alone
  would keep being served from cache; the version bump makes installed
  clients install the new worker and re-precache the new script.

Restore procedure
-----------------
Upload the three files in this directory back to their remote paths above,
then bump the versions again before the next release.
